## 📖 About

AutoHotkey is an open source scripting tool maintained by the AutoHotkey community. It reads plain text scripts and turns them into keyboard shortcuts, text expanders, mouse macros and small automation routines that run in the background on your desktop. The current build targets modern Windows releases and keeps the familiar v1 and v2 script syntaxes working side by side, so older scripts still run without a rewrite.

If you came looking for a AutoHotkey download for Windows 10 or 11, this page lists the current system requirements, install steps and common troubleshooting fixes.

**Good for:** power users · keyboard remappers · data entry staff · gamers building macros · IT admins scripting repetitive tasks · accessibility users · anyone automating window management

## 🛠️ Troubleshooting

| Problem | Solution |
|---|---|
| Setup file blocked by SmartScreen | Click **More info**, then **Run anyway**. |
| Installer closes immediately | Check that you are signed in as an administrator and run the setup file again. |
| Scripts do not run after install | Right click the script file, choose **Open with**, and select the AutoHotkey interpreter. |
| Hotkeys work in some apps but not others | Run the script as administrator, since elevated windows ignore lower integrity input. |
| Tray icon missing | Open Task Manager, end any leftover AutoHotkey process, then relaunch your script. |
| Antivirus flags a compiled script | Compiled scripts are often false positives. Rebuild with the current compiler and report it to your vendor. |
| Old v1 script shows syntax errors | Install the v1 interpreter alongside v2, or update the script to v2 syntax. |
